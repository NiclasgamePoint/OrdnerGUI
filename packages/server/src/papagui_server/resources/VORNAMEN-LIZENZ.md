# Vornamensliste

Die Datei `vornamen.txt` ist eine für PapaGUI auf eine Namensspalte reduzierte
Fassung von `vornamen-grouped-sorted.dat` aus dem Projekt
[fxnn/vornamen](https://github.com/fxnn/vornamen).

- Datenquelle: Stadt Köln, bereitgestellt am 19. Januar 2018
- Upstream-Projekt: https://github.com/fxnn/vornamen
- Lizenz: Creative Commons Namensnennung 3.0 Deutschland (CC BY 3.0 DE)
- Lizenztext: https://creativecommons.org/licenses/by/3.0/de/

Bei der Bearbeitung wurden ausschließlich die Häufigkeitswerte entfernt. Die
Schreibweise und Reihenfolge der Namen entsprechen der Upstream-Datei.
